### 详细描述

```
AI 聚合起始页会替换 Chrome 新标签页，提供一个可自定义的工作入口。

你可以在同一个页面中管理常用网站快捷访问，选择多个 AI 工具或搜索引擎，查看天气、时间、日期、便签和自选股。页面支持插件化布局，可以切换字体、设置背景颜色和透明度，让新标签页更贴合自己的工作流。

核心功能：

• 聚合 ChatGPT、Claude、Grok、Gemini、Kimi、DeepSeek、Qwen、豆包、Perplexity 等 AI 工具
• 聚合 Google、Bing、百度、DuckDuckGo、Brave、GitHub、知乎、B 站等搜索入口
• 管理常用网站快捷访问，支持添加、编辑、删除
• 显示天气、时间、日期、每日金句、便签和自选股
• 支持插件显示/隐藏、字体选择、背景颜色和透明度设置
• 设置默认保存在本地浏览器中

扩展不会修改浏览器默认搜索引擎。AI 和搜索跳转只会在用户主动输入并选择目标服务后发生。
```

## 4. 隐私与权限

### 隐私政策 URL


### 单一用途说明

```
AI 聚合起始页用于替换 Chrome 新标签页，提供一个可自定义的工作入口，聚合 AI 工具、搜索引擎、快捷访问、天气、时间、便签和自选股。
```

### 权限说明

复制以下文本到 CWS 权限说明框：

```
storage：保存用户的新标签页设置、快捷访问、便签、自选股、天气城市和 AI 聚合偏好。

https://query1.finance.yahoo.com/*：用于根据用户添加的股票代码获取自选股行情数据。

https://geocoding-api.open-meteo.com/*：用于把用户设置的天气城市解析为天气查询所需的地理位置。

https://api.open-meteo.com/*：用于获取用户设置城市的天气数据。

AI 服务网站内容脚本权限：用于在用户主动选择 AI 服务并输入提示词后，把该提示词填入对应 AI 服务页面。扩展不会自动读取用户在这些网站上的历史对话内容。
```

### 隐私表单填写

| 问题 | 答案 |
|------|------|
| 是否收集用户数据 | 是，扩展会在本地处理用户为了使用功能而输入或配置的数据 |
| 数据用途 | 应用功能 |
| 不要勾选 | ❌ 广告或营销 / ❌ 数据出售 / ❌ 信用评估 / ❌ 无关分析或追踪 |
| 数据传输 | 扩展开发者没有自有服务器接收用户数据。天气城市发送给 Open-Meteo，股票代码发送给 Yahoo Finance，AI 提示词填入用户选择的 AI 服务页面 |

## 6. 提交审核

确认所有信息填写无误后，点击「提交审核」。

审核通常需要 **1-3 个工作日**，复杂情况可能延长到 1-2 周。

---

## 7. 审核通过后

### Unlisted → Public 切换

1. 在开发者后台找到项目
2. 点击「分发」→「可见性」
3. 从 Unlisted 切换为 Public
4. 保存并发布

### 获取扩展 ID

审核通过后，扩展会获得一个唯一的 CWS ID，格式如：
```
abcdefghijklmnopabcdefghijklmnop
```

这个 ID 可以用于：
- 制作推广链接：`https://chrome.google.com/webstore/detail/ai-聚合起始页/扩展ID`
- 配置 OAuth 等高级功能

## 8. 后续维护

### 更新版本

1. 修改 `package.json` 和 `public/manifest.json` 中的 version
2. 更新 `CHANGELOG.md`
3. 运行 `npm run zip` 生成新 ZIP
4. 在 CWS 后台上传新版本
5. 填写更新说明，提交审核

### 处理用户反馈

- 在 GitHub Issues 中收集反馈
- 定期查看 CWS 开发者后台的用户评价
- 修复 Bug 后尽快发布补丁版本
