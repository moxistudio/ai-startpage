# AI 聚合起始页隐私政策

更新日期：2026-06-10

AI 聚合起始页是一款 Chrome 新标签页扩展，用于聚合 AI 工具、搜索引擎、快捷访问、天气、时间、便签、自选股、热榜、倒计时、番茄钟和计算器等功能。

## 我们处理的数据

扩展会在用户自己的浏览器中保存以下内容和设置：

- 快捷访问的名称和网址
- 便签内容
- 待办、番茄钟和倒计时数据
- 天气城市
- 自选股、行情和加密货币展示偏好
- 搜索源、AI 服务选择和 AI 聚合偏好
- 背景、字体、组件布局、透明度、样式和其他界面设置
- 用户主动输入并用于搜索跳转、AI 页面填入或 AI 小工具调用的文本
- AI 小工具的 OpenAI-compatible Endpoint、Model 和 API Key（如用户主动填写）

这些数据仅用于提供新标签页、快捷访问、天气、行情、热榜、便签、倒计时、番茄钟、搜索和 AI 聚合功能。

## 数据存储位置

扩展开发者没有自有服务器接收或保存用户数据。

用户设置和内容默认保存在用户自己的浏览器本地存储中，包括 `chrome.storage.local` 和扩展页面的 `localStorage`。

目前，AI 小工具的 OpenAI-compatible Endpoint、Model 和 API Key 会保存在扩展页面的 `localStorage` 中。API Key 仅在用户主动填写并点击保存后存储；如果用户不填写 API Key，扩展不会保存或发送 Authorization 信息。用户可以在扩展页面中清空相关输入并保存，以移除已保存的配置。

## 第三方服务请求

扩展在提供部分功能时会访问第三方服务。第三方服务会按照其自身隐私政策处理收到的数据。

### 天气

- `https://geocoding-api.open-meteo.com/*`：把用户输入的天气城市解析为天气查询所需的地理位置。
- `https://api.open-meteo.com/*`：获取用户设置城市的天气数据。

扩展不会读取 GPS 或精确定位；天气城市由用户手动设置。

### 行情和加密货币

- `https://query1.finance.yahoo.com/*`：获取股票、指数等行情数据。
- `https://stooq.com/*`：获取备用股票行情数据。
- `https://api.coingecko.com/*`：获取加密货币价格和涨跌幅数据。

这些请求会包含扩展需要查询的股票代码、指数代码或加密货币标识。

### 热榜

- `https://www.v2ex.com/*`：获取 V2EX 热门主题。
- `https://hn.algolia.com/*`：获取 Hacker News 热门内容。
- `https://api.github.com/*`：获取 GitHub 热门仓库。

热榜请求用于展示公开内容列表。

### AI 和搜索服务

当用户主动使用 AI 或搜索功能时，扩展会根据用户选择打开对应的第三方 AI 或搜索服务。搜索服务会通过目标页面 URL 接收用户输入的查询文本；AI 服务页面交接仅用于把用户输入的提示词填入目标页面的输入框。

部分 AI 服务使用内容脚本完成交接：扩展会在用户主动选择对应 AI 服务并输入提示词后，把该提示词填入对应页面的输入框。扩展不会自动提交该提示词，也不会读取用户在这些 AI 网站上的历史对话内容。

AI 小工具支持 OpenAI-compatible 接口。用户主动配置后，扩展可能访问以下默认或兼容服务域名：

- `https://api.openai.com/*`
- `https://api.deepseek.com/*`
- `https://api.moonshot.cn/*`
- `https://dashscope.aliyuncs.com/*`
- `https://api.siliconflow.cn/*`
- `https://openrouter.ai/*`

AI 小工具调用时会发送用户输入的文本、选择的模型名称，以及用户保存的 API Key（如有）。

## 权限说明

扩展使用以下 Chrome 权限：

- `storage`：保存用户的新标签页设置、快捷访问、便签、自选股、天气城市、AI 聚合偏好、组件布局和界面偏好。
- `activeTab`：在用户主动通过 omnibox 或右键菜单添加快捷访问时，获取当前活动标签页的标题和网址。
- `contextMenus`：提供右键菜单入口，用于把当前页面或链接添加到快捷访问。
- `host_permissions`：允许扩展访问天气、行情、热榜和 AI 小工具所需的第三方接口。
- AI 服务网站内容脚本权限：仅用于在用户主动选择对应 AI 服务时，把用户输入的提示词填入该服务页面；扩展不会自动提交该提示词。

扩展不会使用用户数据进行广告投放、跨站追踪、信用评估，也不会出售、出租或共享用户数据给广告平台、数据经纪商或其他无关第三方。

## 用户控制

用户可以在扩展的新标签页界面中修改或删除快捷访问、便签、待办、倒计时、自选股、天气城市、AI 配置和组件设置。

用户也可以在 Chrome 扩展管理页面中停用或卸载扩展。卸载扩展通常会移除扩展保存在浏览器中的本地数据。
