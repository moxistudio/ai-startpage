# 皮肤生成提示词草案

这些提示词用于生成 16:9 新标签页背景。核心要求：背景不是单纯壁纸，而是和插件位置联动的“桌面皮肤”。图片必须预留插件区域，让搜索框、快捷访问、天气、时间像场景的一部分。

## 通用要求

- 尺寸方向：16:9，适合 1440x900、1920x1080 桌面。
- 不要任何文字、Logo、水印、UI 字样。
- 画面必须给插件留出干净区域：
  - 搜索框区域：画面中部偏右或居中，约 680x90。
  - 快捷访问区域：搜索框下方，约 760x220。
  - 天气区域：左上角，约 180x70。
  - 时间区域：上方或左侧，约 280x100。
- 插件区域可以有场景暗示，比如桌面台面、玻璃窗、控制台面板、留白光区，但不要画出真实 UI 控件。
- 背景主视觉不要被插件挡住，主体应避开插件区域。
- 画面要有高级感、可长期使用，不要过度花哨。

## Orbit / 轨道皮肤

Use case: productivity-visual
Asset type: browser new tab skin background
Primary request: Create a cinematic orbital desk scene for a browser new tab page. A soft futuristic observatory interior, pale warm light, a planet-like circular glow in the upper-right background, subtle orbital rings and glass reflections. Reserve clean translucent surface zones for widgets: a search zone in the center-right, a shortcuts zone below it, weather in the upper-left, and a clock near the top center. No text, no logos, no visible UI controls.
Style: elegant, quiet, premium, not sci-fi cluttered, warm white and muted steel tones.

## 梗图方向候选

- 搜索框像飞船驾驶舱里的主输入槽，但不画具体 UI。
- 快捷访问像桌面上的几张发光便签，实际图标浮在便签上。
- 天气像窗边小仪表，时间像墙上的光影。
- 背景里留一个“空白王座”给搜索框，形成每次打开都是“输入问题启动仪式”的感觉。
