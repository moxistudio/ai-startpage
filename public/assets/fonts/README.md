## Font Library Presets

The page also exposes preset font stacks for fonts that may already be installed on the user's system:

- Chinese: LXGW WenKai, Noto Serif SC, Source Han Serif SC, Noto Sans SC, Source Han Sans SC, ZCOOL XiaoWei, Ma Shan Zheng, Long Cang, Alibaba PuHuiTi.
- English: Oswald, Anton, Teko, Rajdhani, Inter, Space Grotesk, Outfit, Playfair Display, Cormorant Garamond.

Only the files listed above are bundled locally for now. Other presets are configured as font-family stacks so they work when the font exists on the system or is bundled in a later font-pack step.
